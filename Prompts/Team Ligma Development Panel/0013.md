# Prompt
The build panel does not appear to have any option to change the memory limit for docker builds, this was said to be already added.

# Reponse
There was no dedicated control: the memory limit could only be set with a `memory_limit=` line in Template variables, or left automatic. Added a **Memory limit** field (v1.7.4).

- **Settings → Container builds → Memory limit:** a Docker size such as `12g`, `16384m` or `12GB` (saved as `12g`). Empty = automatic, 2 GB per CPU thread capped at the machine's RAM; the placeholder shows the current automatic value.
- Invalid sizes and anything under Docker's 6 MB minimum are refused; values under 2 GB and above this machine's RAM get warnings.
- It fills the template's `{{ memory_limit }}`. The Build Console's **Builds run on** line shows the limit the next build uses.
- **Test connection** shows the value and its source, and warns when a `memory_limit=` line in Template variables overrides the field, or when the template doesn't use `{{ memory_limit }}`.

**Tested against Portainer:** `3 GB` saved as `3g`, and the build container ran with a 3 GiB limit (3221225472 bytes); clearing the field switched back to automatic; `lots` and `1m` were refused. Both parts compile.
