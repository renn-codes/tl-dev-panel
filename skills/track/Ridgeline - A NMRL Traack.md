# Ridgeline - A NMRL Traack
Using any available assets among all the MPQs in the provided WoW folder, design me over an appropriate amount of ADTs, a racetrack for the NO MERCY Racing League module. It is named "`Ridgeline`". It should include a full set of heightmaps along with matching texture alphamaps  after to import into Noggit Red (and the ppropriated textures to assign), and using whatever gameobjects neccessary to flesh out the track path and decorating the landscape as appropriate.

## Track Environemnt and Theming
The track starts in a city/town themed area, then proceeds into a forested area. It then travels along a ridge, and will take a righeside path after a bit down to a coastel ground level, wrapping back into forest then to the starting gate in the city/town area.

## Track Layout
The track should have a fair amount of turns, and a few challenging but not excessively punishing loose corners. It is designed to be weaving, with a rare few straighter, high speed sections. There should be height variance over the track, expecially when traveling down the ridge-side pathway to the shoreline section, as well as over the parts leading up to the ridge section. A full lap should take and average of 2.5-3.5 minutes each, so design appropriately.
